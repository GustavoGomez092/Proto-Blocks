# Scripts module — Playwright E2E (track scripts-e2e)

Spec §8 "Playwright" of `docs/superpowers/specs/2026-11-05-scripts-design.md`.

## Tasks

1. Fixture mu-plugin `tests/e2e/fixtures/mu-plugins/pb-e2e-scripts.php`: calls `proto_script()` only while the
   option `pb_e2e_scripts_php` is set (other specs never see PHP scripts), slug from the option value.
2. `tests/e2e/scripts.spec.ts` (theme `pb-e2e-block`, fresh copy per spec run):
   - fixture script folder written with `writeThemeFile` → head / body-open / body-close markers on the front page,
     in order relative to `<head>`, `<body>`, `</body>`; not on an excluded page (`page:<slug>`).
   - `where.loggedIn` true / false: logged-in vs logged-out request contexts.
   - `url:` glob include.
   - create through the UI (title, priority, three editors, placement builder), read the four files back.
   - edit from the editor and toggle enabled from the list.
   - PHP-declared script → "Proto-Blocks PHP" origin; same slug in a folder → "Declared twice".
   - read-only for a user without `unfiltered_html` (editor + `manage_options`, `unfiltered_html` denied at user
     level), banner reason and disabled controls.
   - delete through the UI removes the folder.
   - `php_in_snippet` refused in the editor (client check) — nothing written.
3. `tests/e2e/scripts-visual.spec.ts`: list and editor baselines (`-chromium-darwin`).
4. Cleanup: every `proto-scripts/` folder, the page, the user and the option removed in `afterEach`/`afterAll`;
   the previous theme re-activated.

## Rulings

- The brief asks for an `editor` user for the read-only case. Editors lack `manage_options` (the screen needs it)
  and have `unfiltered_html` on single site, so the spec creates an `editor`, grants `manage_options` and denies
  `unfiltered_html` on the user (`WP_User::add_cap(cap, false)`), which is exactly the
  "admin without unfiltered_html" situation of multisite / DISALLOW_UNFILTERED_HTML.
- The PHP fixture is gated by an option so the always-mounted mu-plugins folder does not change other specs.
